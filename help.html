Help

Create a route

Enter an address or latitude, longitude directly in Start and Destination. Coordinates are applied automatically; for addresses, press Search or Enter and choose a result. You can also set both points by clicking the map on desktop or holding a point on touch screens. Drag markers to adjust. Calculate route retries the calculation. Use Undo to restore a change, the arrows to reorder, or × to remove a stop.

Touch, suggestions and GPX sharing

On touch screens, a tap closes the point menu. Hold a map point for about half a second, without dragging, then choose Set as start, Add as stop or Set as destination. Desktop clicks still place the selected point; right-click or Shift+F10 opens the same menu. Arrow keys navigate the menu; Escape closes it.

After 3 address characters, Photon offers up to five suggestions. Use arrows and Enter or touch a suggestion; Escape closes the list. Typed text and an approximate map-center bias go to the configured Photon service. If it fails, press Search or Enter for an explicit Nominatim search. Public services have limited capacity; configure another instance before scaling.

Share GPX appears when the browser supports sharing files. It uses the same full track and filename as Download GPX. Cancelling is silent; on failure, download normally. Only the map drawing is simplified at each zoom; exports and saved geometry retain every point.

Map and location

Use Route panel to open or close the side panel or mobile bottom sheet. Its state is remembered in this tab session. Full screen expands the map; press it again or Escape to leave.

Use my location explains why GPS is needed before Continue requests browser permission. Exact location only centers the map and displays an accuracy circle. Set as start and Add as stop use a rounded coordinate (about 100 m); review it before routing. If permission is denied, open this site's permissions in your browser settings and allow Location, then try again. You can keep using the map without GPS.

The initial view prefers the URL route, then already authorized GPS, approximate IP region, and browser timezone/language. To stop IP requests, open Settings and disable Detect region by IP. The selected provider receives your IP address. Exact GPS is never stored or sent to routing services; tile requests reveal the visible area.

Choose main roads

Add stops directly on the roads you want. The road list shows the router’s names and references. “Prefer main roads” flags possible local sections of 500 m or more; it does not exclude all local roads. Major avenues without a reference may also be flagged. Access roads can be necessary.

Saved routes

Enter a GPX name and press Save route. Routes are never saved automatically. The same name updates an existing route. Saved routes lets you open the original geometry, download GPX, delete entries, or export and restore a backup. These files stay in this browser profile, without cloud sync. Clearing browser data can remove them; keep a backup. Matching names in a backup keep your existing saved route.

GPX, import and sharing

Set GPX name above the download button to name the file and track. Leave it empty to use the start and destination. Download GPX exports the complete road geometry and your stops. Import preserves the original geometry until you edit a point. Shared links store points and settings, then recalculate against current road data; they do not embed an imported track.

Round trip adds the return itinerary. On divided roads, check that stops fall on the intended carriageway. Estimated times exclude stops and live traffic.

Travel time

Open Average speed, enable it and drag the slider. Values are 1, 5, 10… up to 200 km/h or 130 mph. Switching units rounds to the nearest position. The estimate excludes stops and traffic. Turn it off or press × to use the router estimate.

Distance units and undo

Choose km or mi beside the road preference. Distances switch between kilometers and miles independently of language; GPX coordinates are unchanged. Undo restores up to 50 changes in this tab, including moved, removed or reordered points. Ctrl+Z or ⌘Z works outside text fields, which keep the normal text undo.

Settings and JSON

Change server base URLs in Settings. Use HTTPS and servers that allow browser requests (CORS). The advanced JSON editor gives you the same points and options used by route links. Hosting your own OSRM is documented in the README.

Public services and privacy

The default servers are public and shared, with limited capacity. Photon suggests addresses while typing; Nominatim is only used by Search or Enter without a selected suggestion, including if suggestions fail. Nominatim requests are spaced at least 1.1 seconds apart; its one-request-per-second limit applies across all users. Use your own service before scaling. Routing changes are debounced and serialized; OSRM falls back to Valhalla.

No cookies, accounts or analytics. Coordinates, searches and visible map tiles are sent to the selected services. Links include your locations. The browser stores a search timestamp to coordinate tabs, and the named routes you explicitly save in local IndexedDB. It also remembers region preferences and panel state without location data. Do not enter confidential addresses.

Ajuda

Criar uma rota

Informe endereço ou latitude, longitude nos campos Início e Destino. Coordenadas são aplicadas automaticamente; para endereços, toque em Buscar ou Enter e escolha um resultado. Também é possível definir os dois pontos clicando no mapa no desktop ou segurando um ponto em telas de toque. Arraste marcadores para ajustar. Calcular rota repete o cálculo. Use Desfazer para recuperar uma alteração, as setas para reordenar ou × para remover uma parada.

Toque, sugestões e compartilhamento de GPX

Em telas de toque, um toque fecha o menu de pontos. Segure um ponto do mapa por cerca de meio segundo, sem arrastar, e escolha Definir como início, Adicionar como parada ou Definir como destino. Cliques no desktop continuam posicionando o ponto selecionado; clique direito ou Shift+F10 abre o mesmo menu. Setas navegam pelo menu; Escape o fecha.

Após 3 caracteres de endereço, Photon oferece até cinco sugestões. Use setas e Enter ou toque em uma sugestão; Escape fecha a lista. O texto digitado e um viés aproximado do centro do mapa vão ao serviço Photon configurado. Se falhar, toque em Buscar ou Enter para uma busca explícita no Nominatim. Os serviços públicos têm capacidade limitada; configure outra instância antes de ampliar o uso.

Compartilhar GPX aparece quando o navegador permite compartilhar arquivos. Usa o mesmo traçado completo e nome de Baixar GPX. Cancelar não mostra erro; em caso de falha, baixe normalmente. Apenas o desenho no mapa é simplificado a cada zoom; exportações e rotas salvas mantêm todos os pontos.

Mapa e localização

Use Painel da rota para abrir ou fechar o painel lateral ou a folha inferior no celular. O estado é lembrado durante a sessão desta aba. Tela cheia expande o mapa; toque novamente ou pressione Escape para sair.

Usar minha localização explica por que o GPS é necessário antes de Continuar solicitar a permissão do navegador. A posição exata só centraliza o mapa e mostra um círculo de precisão. Definir como início e Adicionar como parada usam uma coordenada arredondada (cerca de 100 m); confira antes de calcular. Se a permissão for negada, abra as permissões deste site nas configurações do navegador e libere Localização, depois tente novamente. O mapa continua utilizável sem GPS.

A vista inicial prioriza a rota da URL, GPS já autorizado, região aproximada por IP e fuso/idioma do navegador. Para impedir consultas por IP, abra Configurações e desative Detectar região pelo IP. O provedor escolhido recebe seu endereço IP. O GPS exato nunca é armazenado nem enviado aos roteadores; as requisições de tiles revelam a área visível.

Escolher vias principais

Adicione paradas diretamente nas vias desejadas. A lista mostra os nomes e referências retornados pelo roteador. “Preferir vias principais” sinaliza possíveis trechos locais com 500 m ou mais; não exclui todas as vias locais. Avenidas principais sem referência também podem ser sinalizadas. Vias de acesso podem ser necessárias.

Rotas salvas

Preencha Nome do GPX e toque em Salvar rota. Nenhuma rota é salva automaticamente. Um nome existente atualiza a entrada. Em Rotas salvas, reabra a geometria original, baixe o GPX, exclua entradas ou exporte e restaure um backup. Os arquivos ficam neste perfil do navegador, sem nuvem. Limpar os dados do navegador pode apagá-los; guarde um backup. Nomes iguais no backup mantêm a rota que já está salva.

GPX, importação e links

Defina Nome do GPX acima do botão de download para nomear o arquivo e o trajeto. Se ficar vazio, usa origem e destino. O botão “Baixar GPX” exporta o trajeto completo e suas paradas. Importar preserva a geometria original até você editar um ponto. Links compartilhados guardam pontos e opções e recalculam com os dados atuais; não incluem a geometria original de um arquivo importado.

Ida e volta adiciona o retorno ao itinerário. Em vias de pistas separadas, confira se os pontos estão na pista desejada. As durações não incluem paradas nem trânsito em tempo real.

Tempo de viagem

Abra Velocidade média, ative e arraste o controle. Os valores são 1, 5, 10… até 200 km/h ou 130 mph. A troca de unidade arredonda para a posição mais próxima. A estimativa não inclui paradas nem trânsito. Desative ou toque em × para usar a estimativa do roteador.

Unidades de distância e desfazer

Escolha km ou mi ao lado da preferência de vias. As distâncias mudam entre quilômetros e milhas, independente do idioma; as coordenadas do GPX permanecem iguais. Desfazer recupera até 50 alterações nesta aba, incluindo pontos movidos, removidos ou reordenados. Ctrl+Z ou ⌘Z funciona fora dos campos de texto, que mantêm a função de desfazer a digitação.

Configurações e JSON

Altere as URLs base dos servidores nas Configurações. Use HTTPS e servidores que permitam requisições do navegador (CORS). O editor JSON avançado usa os mesmos pontos e opções dos links de rota. O README explica como hospedar seu próprio OSRM.

Serviços públicos e privacidade

Os servidores padrão são públicos, compartilhados e têm capacidade limitada. Photon sugere endereços ao digitar; Nominatim só é usado por Buscar ou Enter sem sugestão selecionada, inclusive se as sugestões falharem. As consultas Nominatim têm ao menos 1,1 s entre requisições; o limite de uma requisição por segundo vale para todos os usuários. Use uma instância própria antes de ampliar o uso. O roteamento tem debounce e fila; o Valhalla é usado se o OSRM falhar.

Sem cookies, cadastro ou analytics. Coordenadas, buscas e área visível do mapa são enviados aos serviços escolhidos. Links incluem seus locais. O navegador guarda um horário de busca para coordenar abas e as rotas nomeadas que você salvar explicitamente no IndexedDB local. Também lembra preferências de região e estado do painel, sem dados de localização. Não informe endereços confidenciais.
