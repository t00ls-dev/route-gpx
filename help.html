Help

Create a route

Enter an address or latitude, longitude directly in Start and Destination. Coordinates are applied automatically; for addresses, choose a suggestion while typing, or press Enter for an explicit search. You can also set both points by clicking the map on desktop or holding a point on touch screens. Drag markers to adjust. Calculate route retries the calculation. Use Undo to restore a change, the arrows to reorder, or × to remove a stop.

On small screens, the right column contains location, layers, full screen, fit route, undo and lock icons. Each has a tooltip and accessible name. Zoom with a two-finger pinch or a double tap; Fit route frames the whole route. The header Help icon opens these instructions; address fields suggest places as you type; the pin icon selects the point on the map.

Map layers

Tap the circular i button at the bottom right to open the active layer's full map credits and licenses. Links open in a new tab. Close, Escape or a tap outside the card closes the modal and returns focus to i. Changing layers closes it and updates its contents. On small screens, close the route panel to access the control.

Open Map layers to choose Standard (OpenStreetMap), Topographic (OpenTopoMap, CC BY-SA 3.0) or Satellite (EOX Sentinel-2 cloudless 2025, CC BY-NC-SA 4.0, non-commercial only). Satellite Labels are on by default and can be switched off. For commercial use, choose the EOX 2016 edition (CC BY 4.0) in Settings. Satellite imagery is a regional mosaic, not live or street-level imagery; zooming beyond its native level enlarges pixels.

Only the active layer and enabled labels request tiles. Their providers receive your IP and visible map area. Keep the credits visible and follow fair-use limits; no availability is guaranteed. The device remembers your choice outside shared routes; changing layers leaves the complete GPX untouched. Use arrows and Enter in the layer menu, or Escape to close it. Sources and license links are listed in the services and privacy details.

Touch, suggestions and GPX sharing

On touch screens, a tap closes the point menu. Hold a map point for about half a second, without dragging, then choose Set as start, Add as stop or Set as destination. Desktop clicks still place the selected point; right-click or Shift+F10 opens the same menu. Arrow keys navigate the menu; Escape closes it.

After 3 address characters, Photon offers up to five suggestions. Numeric coordinates, including incomplete input, stay local. Use arrows and Enter or touch a suggestion; Escape closes the list. Typed text and an approximate map-center bias go to the configured Photon service. If it fails, press Enter for an explicit Nominatim search. Public services have limited capacity; configure another instance before scaling.

Share GPX appears when the browser supports sharing files. It uses the same full track and filename as Download GPX. Cancelling is silent; on failure, download normally. Only the map drawing is simplified at each zoom; exports and saved geometry retain every point.

Map and location

Use Route panel to open or close the side panel or mobile bottom sheet. Its state is remembered in this tab session. Full screen expands the map; press it again or Escape to leave.

Use my location requests your position directly. The browser asks for permission when needed, without a preliminary confirmation screen. Exact location only centers the map and displays an accuracy circle. Set as start and Add as stop use a rounded coordinate (about 100 m); review it before routing. If permission is denied, open this site's permissions in your browser settings and allow Location, then try again. You can keep using the map without GPS.

The initial view prefers the URL route, then already authorized GPS, approximate IP region, and browser timezone/language. To stop IP requests, open Settings and disable Detect region by IP. The selected provider receives your IP address. Exact GPS is never stored or sent to routing services; tile requests reveal the visible area.

Choose main roads

Add stops directly on the roads you want. The road list shows the router’s names and references. “Prefer main roads” flags possible local sections of 500 m or more; it does not exclude all local roads. Major avenues without a reference may also be flagged. Access roads can be necessary.

Recent router results stay in page memory for 15 minutes, up to 20 routes. Returning to the same points and routing settings reuses them; Calculate route requests a fresh result. Reloading clears this cache.

Saved routes

Enter a GPX name and press Save route. Routes are never saved automatically. The same name updates an existing route. Saved routes, above Average speed, lets you open the original geometry, download GPX, delete entries, or export and restore a backup. These files stay in this browser profile, without cloud sync. Clearing browser data can remove them; keep a backup. Matching names in a backup keep your existing saved route.

GPX, import and sharing

Set GPX name above the download button to name the file and track. Leave it empty to use the start and destination. Download GPX exports the complete road geometry and your stops. Import preserves the original geometry. A track without waypoints gets stops where its shape needs them (loops, out-and-back sections and large bends). Editing a point recalculates only the sections next to it; the rest of the imported track stays exact. Removing a stop, Reverse and Round trip reuse the imported track without a new request; a recalculated section joins any gap between track segments. Calculate route recalculates the whole route through your points. Shared links store points and settings, then recalculate against current road data; they do not embed an imported track.

Round trip adds the return itinerary. On divided roads, check that stops fall on the intended carriageway. Estimated times exclude stops and live traffic.

Departure and weather

Choose Departure in the route summary, which appears once the route is ready. Then weather loads automatically after a short pause. There is no request without a date. Choosing a date sends sampled points and expected dates/times to Open-Meteo. Weather passage times use the value enabled in Average speed, or 60 km/h when it is off. Adjust it for your journey. Stops and traffic are excluded. All displayed times use the device timezone. Departures in the last 90 UTC calendar days are accepted. Older departures and arrival windows beyond 16 UTC calendar days including today are rejected. For past dates, values are archived model estimates, not exact observations at each route point. Imported GPX works too. Samples include endpoints and waypoints, approximately every 20 km. Below 20 km/h, spacing is reduced to about one hour of travel (5 km at 5 km/h, for example). The maximum of 20 points takes priority and may require larger gaps. Select a weather icon on the map to open its weather card in the panel. Selecting a card centers the map on its point and collapses the mobile panel; Enter and Space work too.

Speed changes recalculate locally if coverage permits; use Try again if the interval is exceeded. Slower travel automatically requests additional points if needed for the shorter spacing; faster travel reuses the existing points without another request. Track, date or server changes automatically update the weather. Errors allow a manual retry, never automatic retry loops. Weather data and sample coordinates stay only in page memory, never in storage, application logs or links. Only departure is new persisted trip data, in normal links and explicitly saved routes. Reopening requests weather again. GPX point timestamps are not added.

Hourly temperature, precipitation probability/volume, weather code, wind speed/direction, gusts and visibility come from Open-Meteo, under CC BY 4.0. Weather data by Open-Meteo; passage times and risk summaries calculated by route-gpx. The free API is non-commercial only, no key, HTTPS/CORS; its base URL is configurable in Settings. Limits: 600 calls/minute, 5,000/hour, 10,000/day and 300,000/month. Every location counts even in one grouped request; over 10 variables or two weeks increases call accounting. Requests are at least six seconds apart with conservative memory budgets, a ten-minute memory cache and a 20-second timeout. The cache holds up to 200 locations and 100,000 hourly entries, reusing covered locations and grouping only missing ones. Hits do not extend freshness. Page limits cannot enforce aggregate usage. Terms · Call accounting · Documentation.

Forecasts are approximate, on a grid of several kilometres, and may miss local showers; passage times depend on stops and traffic. Risk alerts are review aids, not official warnings: worst case within ±1 hour, rounded outward. Rain: ≥60% probability or ≥1 mm/h; heavy rain ≥10 mm/h; thunderstorm codes 95/96/99; fog codes 45/48 or visibility ≤1,000 m; gusts ≥60 km/h; cold/possible ice ≤2 °C or freezing codes; extreme heat ≥40 °C. Alerts are ordered by severity; missing data is flagged. Real forecast accuracy has not been evaluated.

Each sampled point has one card combining weather and risk, without a separate alert list. Alert 1, 2 and 3 use yellow, orange and red plus text labels; no-alert cards are neutral. All cards use the main panel scroll.

Cards use matching outline SVG icons; map markers use colored, centered weather icons. The wind icon accompanies the relative direction and speed. Wind compares the direction it comes from with the local track direction: headwind within 45° ahead, tailwind within 45° behind, otherwise crosswind. Below 1 km/h is calm. The nearest weather hour is used, with speed in km/h or mph. Bends use the outgoing edge; the destination uses the incoming edge. This is model wind at 10 m, not apparent wind or resistance experienced by a vehicle. Terrain and shelter can change local wind. Missing direction or speed is reported explicitly. Map arrows point toward where wind blows and show speed. Colors indicate headwind (red), tailwind (green), crosswind (amber), or calm/unavailable (gray), also identified by text. Accessible labels classify mean wind as calm <1 km/h, light 1–<20, moderate 20–<39, strong 39–<62 and very strong ≥62: simplified Beaufort bands, separate from gust alerts. Direction follows the meteorological convention.

Daylight

The route summary shows sunrise and sunset at the start, with a rising and a setting sun icon. Without a departure date it shows today's times; with one, it also shows how much of the route falls in the dark. Open Daylight in the summary for the dark sections with their passage times, the distance in civil twilight, the latest departure that arrives before sunset and when daylight starts at the start.

Everything is calculated on your device, with no request. Sunrise and sunset are when the sun's upper edge crosses a sea-level horizon (0.833° below it, including refraction); civil twilight lasts until the sun is 6° below the horizon, and after that the route counts as dark. Passage times use the same speed as weather, without stops, and times use your device's time zone. Mountains, valleys, clouds and street lighting change the real light. Near the poles the sun may stay up or down all day.

Travel time

Open Average speed in the route summary, enable it and drag the slider. Values are 1, 5, 10… up to 200 km/h or 130 mph. Switching units rounds to the nearest position. The estimate excludes stops and traffic. Turn it off or press × to use the router estimate. The route summary, right below Calculate route, holds the departure date and shows the distance, the time and, when a departure is set, the arrival time, with a line saying whether the time comes from the router or from your average speed. Itinerary, below the summary, shows the highway references, each road with its distance and the routing provider.

Distance units and undo

Choose km or mi beside the road preference. Distances switch between kilometers and miles independently of language; GPX coordinates are unchanged. Undo restores up to 50 changes in this tab, including moved, removed or reordered points. Ctrl+Z or ⌘Z works outside text fields, which keep the normal text undo.

Lock editing

The padlock in the map tools locks the route against accidental changes. While it is locked, points cannot be added, moved, edited, reordered or removed, and undo, Calculate route, GPX import, opening a saved route, Apply JSON and routing server changes are paused. Zoom, map layers, weather, the route summary, download, sharing and saving still work. The lock lasts until you unlock it or reload the page.

Settings and JSON

Change server base URLs in Settings. A route link that suggests other routing or search servers opens with the default servers; a notice names them, and Use link servers applies them only if you choose. Use HTTPS and servers that allow browser requests (CORS). The advanced JSON editor gives you the same points and options used by route links. Routing and address-search servers belong to the route and travel with links, saved routes and backups; the suggestion, weather and IP-region servers stay on this device only. Provider behavior and usage limits are described in the services and privacy details.

Public services and privacy

The default servers are public and shared, with limited capacity. Photon suggests addresses while typing; Nominatim is only used by Enter without a selected suggestion, including if suggestions fail. Nominatim requests are spaced at least 1.1 seconds apart; its one-request-per-second limit applies across all users. Use your own service before scaling. Routing changes are debounced and serialized; OSRM falls back to Valhalla.

No cookies, accounts or analytics. Coordinates, searches and visible map tiles are sent to the selected services. Links include your locations. The browser stores a search timestamp to coordinate tabs, and the named routes you explicitly save in local IndexedDB. It also remembers language, region preferences and panel state without location data. Do not enter confidential addresses.

Nominatim policy · Tile policy

Routing sends control coordinates and options to https://router.project-osrm.org or, on fallback, https://valhalla1.openstreetmap.de. The route data uses OpenStreetMap/ODbL. The OSRM operator documents a one-request/second limit and server-side route logs; the page spaces routing starts by at least 1.5 seconds. A separate Valhalla numeric quota was not verified. Address text goes to https://photon.komoot.io while typing or https://nominatim.openstreetmap.org on Enter; both use OSM/ODbL data.

IP region requests use https://ipwho.is/. Its free-endpoint documentation permits keyless commercial use, but general terms also contain account and redistribution clauses whose applicability should be confirmed before scaling. Weather uses https://api.open-meteo.com. Map images use https://tile.openstreetmap.org, https://a.tile.opentopomap.org or https://tiles.maps.eox.at, including the EOX label overlay. Only the active layer requests images. GitHub Pages receives requests for the site files. External providers receive the request IP and normal browser metadata and may keep their own logs. URL fragments are not sent in HTTP requests. Browser HTTP caching of ordinary map tiles follows provider headers; there is no added offline storage.

Ajuda

Criar uma rota

Informe endereço ou latitude, longitude nos campos Início e Destino. Coordenadas são aplicadas automaticamente; para endereços, toque em escolha uma sugestão enquanto digita, ou pressione Enter para uma busca explícita. Também é possível definir os dois pontos clicando no mapa no desktop ou segurando um ponto em telas de toque. Arraste marcadores para ajustar. Calcular rota repete o cálculo. Use Desfazer para recuperar uma alteração, as setas para reordenar ou × para remover uma parada.

Em telas pequenas, a coluna à direita contém ícones de localização, camadas, tela cheia, ver rota, desfazer e bloqueio. Cada um tem dica e nome acessível. Use o gesto de pinça com dois dedos ou um toque duplo para o zoom; Ver rota enquadra a rota inteira. O ícone de Ajuda no cabeçalho abre estas instruções; os campos de endereço sugerem locais ao digitar; o ícone de pin seleciona o ponto no mapa.

Camadas do mapa

Toque no botão circular i no canto inferior direito para abrir os créditos completos e as licenças da camada ativa. Os links abrem em nova aba. Fechar, Escape ou um toque fora do card fecha o modal e devolve o foco ao i. Trocar de camada fecha o modal e atualiza seu conteúdo. Em telas pequenas, feche o painel da rota para acessar o controle.

Abra Camadas do mapa e escolha Padrão (OpenStreetMap), Topográfico (OpenTopoMap, CC BY-SA 3.0) ou Satélite (EOX Sentinel-2 cloudless 2025, CC BY-NC-SA 4.0, apenas uso não comercial). Os Rótulos do satélite começam ligados e podem ser desligados. Para uso comercial, escolha a edição EOX 2016 (CC BY 4.0) em Configurações. O satélite é um mosaico regional, não uma imagem ao vivo nem em nível de rua; o zoom acima do nível nativo amplia os pixels.

Só a camada ativa e os rótulos habilitados requisitam tiles. Seus provedores recebem seu IP e a área visível do mapa. Mantenha os créditos visíveis e respeite os limites de uso justo; não há garantia de disponibilidade. O aparelho lembra sua escolha fora das rotas compartilhadas; trocar camadas mantém o GPX completo intacto. Use setas e Enter no menu ou Escape para fechá-lo. Fontes e links das licenças estão nos detalhes de serviços e privacidade (em inglês).

Toque, sugestões e compartilhamento de GPX

Em telas de toque, um toque fecha o menu de pontos. Segure um ponto do mapa por cerca de meio segundo, sem arrastar, e escolha Definir como início, Adicionar como parada ou Definir como destino. Cliques no desktop continuam posicionando o ponto selecionado; clique direito ou Shift+F10 abre o mesmo menu. Setas navegam pelo menu; Escape o fecha.

Após 3 caracteres de endereço, Photon oferece até cinco sugestões. Coordenadas numéricas, inclusive incompletas, ficam no aparelho. Use setas e Enter ou toque em uma sugestão; Escape fecha a lista. O texto digitado e um viés aproximado do centro do mapa vão ao serviço Photon configurado. Se falhar, pressione Enter para uma busca explícita no Nominatim. Os serviços públicos têm capacidade limitada; configure outra instância antes de ampliar o uso.

Compartilhar GPX aparece quando o navegador permite compartilhar arquivos. Usa o mesmo traçado completo e nome de Baixar GPX. Cancelar não mostra erro; em caso de falha, baixe normalmente. Apenas o desenho no mapa é simplificado a cada zoom; exportações e rotas salvas mantêm todos os pontos.

Mapa e localização

Use Painel da rota para abrir ou fechar o painel lateral ou a folha inferior no celular. O estado é lembrado durante a sessão desta aba. Tela cheia expande o mapa; toque novamente ou pressione Escape para sair.

Usar minha localização solicita a posição diretamente. O navegador pede permissão quando necessário, sem tela preliminar de confirmação. A posição exata só centraliza o mapa e mostra um círculo de precisão. Definir como início e Adicionar como parada usam uma coordenada arredondada (cerca de 100 m); confira antes de calcular. Se a permissão for negada, abra as permissões deste site nas configurações do navegador e libere Localização, depois tente novamente. O mapa continua utilizável sem GPS.

A vista inicial prioriza a rota da URL, GPS já autorizado, região aproximada por IP e fuso/idioma do navegador. Para impedir consultas por IP, abra Configurações e desative Detectar região pelo IP. O provedor escolhido recebe seu endereço IP. O GPS exato nunca é armazenado nem enviado aos roteadores; as requisições de tiles revelam a área visível.

Escolher vias principais

Adicione paradas diretamente nas vias desejadas. A lista mostra os nomes e referências retornados pelo roteador. “Preferir vias principais” sinaliza possíveis trechos locais com 500 m ou mais; não exclui todas as vias locais. Avenidas principais sem referência também podem ser sinalizadas. Vias de acesso podem ser necessárias.

Resultados recentes do roteador ficam na memória da página por 15 minutos, até 20 rotas. Voltar aos mesmos pontos e configurações reaproveita o resultado; Calcular rota solicita um novo. Recarregar limpa esse cache.

Rotas salvas

Preencha Nome do GPX e toque em Salvar rota. Nenhuma rota é salva automaticamente. Um nome existente atualiza a entrada. Em Rotas salvas, acima de Velocidade média, reabra a geometria original, baixe o GPX, exclua entradas ou exporte e restaure um backup. Os arquivos ficam neste perfil do navegador, sem nuvem. Limpar os dados do navegador pode apagá-los; guarde um backup. Nomes iguais no backup mantêm a rota que já está salva.

GPX, importação e links

Defina Nome do GPX acima do botão de download para nomear o arquivo e o trajeto. Se ficar vazio, usa origem e destino. O botão “Baixar GPX” exporta o trajeto completo e suas paradas. Importar preserva a geometria original. Um trajeto sem paradas ganha paradas onde o formato precisa delas (laços, idas e voltas e curvas grandes). Editar um ponto recalcula só os trechos vizinhos; o resto do trajeto importado continua exato. Remover uma parada, Inverter e Ida e volta reaproveitam o trajeto importado sem nova solicitação; um trecho recalculado une eventuais intervalos entre segmentos do trajeto. Calcular rota recalcula a rota inteira pelos seus pontos. Links compartilhados guardam pontos e opções e recalculam com os dados atuais; não incluem a geometria original de um arquivo importado.

Ida e volta adiciona o retorno ao itinerário. Em vias de pistas separadas, confira se os pontos estão na pista desejada. As durações não incluem paradas nem trânsito em tempo real.

Saída e clima

Escolha Saída no resumo da rota, que aparece quando a rota está pronta. Então o clima carrega automaticamente após uma breve pausa. Sem data não há consulta. Escolher uma data envia pontos de amostragem e datas/horários previstos ao Open-Meteo. Os horários de passagem do clima usam o valor ativado em Velocidade média, ou 60 km/h quando ela está desligada. Ajuste ao seu deslocamento. Paradas e trânsito não são incluídos. Todos os horários usam o fuso do aparelho. São aceitas saídas nos últimos 90 dias de calendário UTC. Saídas anteriores e janelas de chegada além de 16 dias de calendário UTC incluindo hoje são rejeitadas. Para datas passadas, os valores são estimativas arquivadas dos modelos, não observações exatas em cada ponto da rota. Também funciona com GPX importado. As amostras incluem origem, destino e passagens, aproximadamente a cada 20 km. Abaixo de 20 km/h, o espaçamento é reduzido para cerca de uma hora de deslocamento (5 km a 5 km/h, por exemplo). O máximo de 20 pontos tem prioridade e pode exigir intervalos maiores. Selecione um ícone de tempo no mapa para abrir seu card de clima no painel. Selecionar um card centraliza o mapa no ponto e recolhe o painel no celular; Enter e Espaço também funcionam.

Alterar a velocidade recalcula localmente se houver cobertura; use Tentar novamente se ultrapassar o intervalo. Deslocamentos mais lentos consultam automaticamente pontos adicionais se o espaçamento menor exigir; deslocamentos mais rápidos reaproveitam os pontos existentes sem nova consulta. Alterar traçado, data ou servidor atualiza automaticamente o clima. Erros permitem tentar manualmente, sem ciclos automáticos de repetição. Dados do clima e coordenadas de amostragem ficam só na memória da página, nunca em armazenamento, logs ou links. Apenas a saída é um novo dado da viagem persistido, nos links normais e rotas salvas explicitamente. Ao reabrir, o clima é consultado novamente. Não são adicionados horários aos pontos do GPX.

Temperatura horária, probabilidade/volume de precipitação, código do tempo, velocidade/direção do vento, rajadas e visibilidade vêm do Open-Meteo, sob CC BY 4.0. Dados do tempo por Open-Meteo; horários de passagem e resumos de risco calculados pelo route-gpx. A API gratuita é só para uso não comercial, sem chave, com HTTPS/CORS; a URL base é configurável em Configurações. Limites: 600 chamadas/minuto, 5.000/hora, 10.000/dia e 300.000/mês. Cada localização conta mesmo numa requisição agrupada; mais de 10 variáveis ou duas semanas aumenta a contagem. Consultas têm intervalo mínimo de seis segundos com orçamentos conservadores em memória, cache em memória de dez minutos e timeout de 20 segundos. Limites por página não controlam uso agregado. O cache guarda até 200 localizações e 100.000 registros horários, reaproveitando locais cobertos e agrupando somente os ausentes. Reutilizar não prolonga a validade. Termos · Contagem de chamadas · Documentação.

A previsão é aproximada, em grade de alguns quilômetros, e pode não captar pancadas locais; a hora de passagem depende de paradas e trânsito. Alertas de risco auxiliam a revisão, não são avisos oficiais: pior caso em ±1 hora, arredondada para fora. Chuva: probabilidade ≥60% ou ≥1 mm/h; chuva forte ≥10 mm/h; códigos de trovoada 95/96/99; códigos de neblina 45/48 ou visibilidade ≤1.000 m; rajadas ≥60 km/h; frio/possível gelo ≤2 °C ou códigos de congelamento; calor extremo ≥40 °C. Alertas são ordenados por gravidade; dados ausentes são sinalizados. A precisão real da previsão não foi avaliada.

Cada ponto amostrado tem um único card com condições e riscos, sem lista separada de alertas. Alerta 1, 2 e 3 usam amarelo, laranja e vermelho, além de rótulos; sem alerta, o card é neutro. Todos usam a rolagem do painel principal.

Os cards usam ícones SVG em traço no mesmo estilo; o mapa usa ícones de clima coloridos e centralizados. O ícone de vento acompanha a direção relativa e a velocidade. O vento compara a direção de onde vem com o sentido local do traçado: contra até 45° pela frente, a favor até 45° por trás e lateral nos demais casos. Abaixo de 1 km/h é calmo. Usa-se a hora de clima mais próxima, com velocidade em km/h ou mph. Em curvas usa-se o trecho de saída; no destino, o de chegada. É vento do modelo a 10 m, não vento aparente nem resistência sentida por um veículo. Relevo e abrigo podem alterar o vento local. A falta de direção ou velocidade é indicada explicitamente. As setas no mapa apontam para onde o vento sopra e mostram a velocidade. As cores indicam vento contra (vermelho), a favor (verde), lateral (âmbar) ou calmo/indisponível (cinza), também identificados por texto. Os rótulos acessíveis classificam o vento médio em calmo <1 km/h, fraco 1–<20, moderado 20–<39, forte 39–<62 e muito forte ≥62: faixas simplificadas de Beaufort, separadas dos alertas de rajadas. A direção segue a convenção meteorológica.

Luz do dia

O resumo da rota mostra o nascer e o pôr do sol no início, com ícones de sol nascendo e se pondo. Sem data de saída, mostra os horários de hoje; com ela, mostra também quanto da rota fica no escuro. Abra Luz do dia no resumo para ver os trechos no escuro com os horários de passagem, a distância no crepúsculo civil, a saída mais tarde que chega antes do pôr do sol e quando a luz do dia começa no início.

Tudo é calculado no seu aparelho, sem nenhuma requisição. O nascer e o pôr do sol são os momentos em que a borda superior do sol cruza um horizonte ao nível do mar (0,833° abaixo dele, incluindo a refração); o crepúsculo civil dura até o sol ficar 6° abaixo do horizonte, e a partir daí a rota conta como escura. Os horários de passagem usam a mesma velocidade do clima, sem paradas, e o fuso horário do seu aparelho. Serras, vales, nuvens e iluminação pública mudam a luz real. Perto dos polos, o sol pode ficar acima ou abaixo do horizonte o dia todo.

Tempo de viagem

Abra Velocidade média no resumo da rota, ative e arraste o controle. Os valores são 1, 5, 10… até 200 km/h ou 130 mph. A troca de unidade arredonda para a posição mais próxima. A estimativa não inclui paradas nem trânsito. Desative ou toque em × para usar a estimativa do roteador. O resumo da rota, logo abaixo de Calcular rota, traz a data de saída e mostra a distância, o tempo e, quando há saída, o horário de chegada, com uma linha dizendo se o tempo vem do roteador ou da sua velocidade média. Itinerário, abaixo do resumo, mostra as rodovias, cada via com sua distância e o provedor de rotas.

Unidades de distância e desfazer

Escolha km ou mi ao lado da preferência de vias. As distâncias mudam entre quilômetros e milhas, independente do idioma; as coordenadas do GPX permanecem iguais. Desfazer recupera até 50 alterações nesta aba, incluindo pontos movidos, removidos ou reordenados. Ctrl+Z ou ⌘Z funciona fora dos campos de texto, que mantêm a função de desfazer a digitação.

Bloquear edição

O cadeado nas ferramentas do mapa protege a rota contra alterações acidentais. Enquanto estiver bloqueada, não é possível adicionar, mover, editar, reordenar ou remover pontos, e ficam pausados desfazer, Calcular rota, importar GPX, abrir rota salva, Aplicar JSON e mudanças de servidor de rotas. Zoom, camadas do mapa, clima, resumo da rota, download, compartilhamento e salvar continuam funcionando. O bloqueio dura até você desbloquear ou recarregar a página.

Configurações e JSON

Altere as URLs base dos servidores nas Configurações. Um link de rota que sugere outros servidores de rota ou busca abre com os servidores padrão; um aviso mostra quais são, e Usar servidores do link só os aplica se você escolher. Use HTTPS e servidores que permitam requisições do navegador (CORS). O editor JSON avançado usa os mesmos pontos e opções dos links de rota. Os servidores de rota e de busca de endereço fazem parte da rota e acompanham links, rotas salvas e backups; os servidores de sugestões, clima e região por IP ficam só neste aparelho. Os detalhes de serviços e privacidade (em inglês) descrevem o comportamento e os limites de uso dos provedores.

Serviços públicos e privacidade

Os servidores padrão são públicos, compartilhados e têm capacidade limitada. Photon sugere endereços ao digitar; Nominatim só é usado por Enter sem sugestão selecionada, inclusive se as sugestões falharem. As consultas Nominatim têm ao menos 1,1 s entre requisições; o limite de uma requisição por segundo vale para todos os usuários. Use uma instância própria antes de ampliar o uso. O roteamento tem debounce e fila; o Valhalla é usado se o OSRM falhar.

Sem cookies, cadastro ou analytics. Coordenadas, buscas e área visível do mapa são enviados aos serviços escolhidos. Links incluem seus locais. O navegador guarda um horário de busca para coordenar abas e as rotas nomeadas que você salvar explicitamente no IndexedDB local. Também lembra idioma, preferências de região e estado do painel, sem dados de localização. Não informe endereços confidenciais.

Política do Nominatim · Política de tiles

O roteamento envia coordenadas de controle e opções a https://router.project-osrm.org ou, na alternativa, https://valhalla1.openstreetmap.de. Os dados usam OpenStreetMap/ODbL. O operador OSRM documenta o limite de uma requisição/segundo e logs de rotas no servidor; a página espaça inícios de roteamento por ao menos 1,5 segundo. Não foi verificada uma cota numérica separada para o Valhalla. O texto de endereço vai a https://photon.komoot.io ao digitar ou a https://nominatim.openstreetmap.org por Enter; ambos usam dados OSM/ODbL.

Consultas de região por IP usam https://ipwho.is/. A documentação do endpoint gratuito permite uso comercial sem chave, mas os termos gerais também contêm cláusulas de conta e redistribuição cuja aplicação deve ser confirmada antes de ampliar o uso. O clima usa https://api.open-meteo.com. Imagens do mapa usam https://tile.openstreetmap.org, https://a.tile.opentopomap.org ou https://tiles.maps.eox.at, incluindo a sobreposição de rótulos EOX. Só a camada ativa solicita imagens. O GitHub Pages recebe pedidos dos arquivos do site. Provedores externos recebem o IP da requisição e metadados normais do navegador e podem manter logs próprios. Fragmentos de URL não são enviados nas requisições HTTP. O cache HTTP comum dos tiles segue os cabeçalhos dos provedores; não há armazenamento offline adicional.
